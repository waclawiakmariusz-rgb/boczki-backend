# Rabaty — pakiet dla Claude Code

1. Przeczytaj `RABATY_WDROZENIE_DLA_CLAUDE.md`.
2. Obejrzyj `makiety/01-rabaty-desktop.png`.
3. Wdrażaj wyłącznie obszar treści widoku Rabaty w istniejącej aplikacji.

Makieta używa danych przykładowych. Menu, pozostałe moduły oraz biznesowe reguły rabatów nie są przedmiotem przebudowy. Parametry CSS i zachowania w MD rozstrzygają niedokładności obrazu.

Ta paczka zawiera projekt i instrukcje, bez kodu HTML/CSS/JS. Zasady kolejnych paczek opisuje `ESTELIO_STANDARD_REDESIGNU.md`.

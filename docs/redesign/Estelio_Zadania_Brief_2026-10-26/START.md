# Estelio — Zadania na Pulpicie: brief dla ChatGPT (26.10.2026)

Kolejność czytania:
1. `BRIEF_DLA_CHATGPT_Zadania_Pulpit.md` — główny dokument: kontekst, fakty z kodu i danych, diagnoza, docelowy model, lista makiet, zasady stylu, kryteria odbioru.
2. `PROMPT_MAKIETY.txt` — gotowy prompt na makietę (a) w stylu poprzednich pakietów; makiety (b)–(d) wyprowadzić z briefu.
3. `zrodla/01-pulpit-zadania-obecnie-ciemny.png` — zrzut obecnego widgetu (tryb ciemny) z zgłoszenia recepcji; wyłącznie kontekst, dane prawdziwe — nie przenosić nazwisk ani numerów na makiety.

Standard dostarczenia: jak w `ESTELIO_STANDARD_REDESIGNU.md` z pakietu Zadatki (paczka ZIP: makiety PNG + instrukcja MD dla Claude Code + START). Kodu nie zamawiamy.

Kierunek ustalony przez właściciela: **nie kasować funkcjonalności** (kategorie, komentarze, cykliczne, powiązania zostają) — wypracować lepszy model prezentacji i dodać pojęcie „telefon”.

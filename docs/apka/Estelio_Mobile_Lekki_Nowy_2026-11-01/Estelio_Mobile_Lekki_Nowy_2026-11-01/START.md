# Estelio Mobile — pakiet v0.2, po lekturze pomocy

01.11.2026 · Projekt aplikacji pracowniczej Android/iOS · Recepcja + Manager.

Ta wersja zastępuje założenia v0.1. Główne źródła: aktualne działy Pomoc, Pomoc managera i Pomoc terminarza. Nie jest to projekt aplikacji Klubu dla klientek ani nowy redesign całej wersji WWW.

## Kolejność

1. `00_CO_ZMIENIONO.md` — konkretne korekty po lekturze.
2. `makiety/index.html` — klikalny prototyp; otwórz lokalnie w przeglądarce. Dane fikcyjne, bez połączeń z Estelio. Przełącz rolę, ekran, stan i dostępność dodatków.
3. `01_PLAN_PRODUKTU.md` oraz `04_MAKIETY_I_UX.md` — zakres, etapy i kontrakt ekranów.
4. `02_ARCHITEKTURA_I_DYSTRYBUCJA.md` i `03_ZABEZPIECZENIA.md` — warianty techniczne i wymagania.
5. Przekaż Claude Code `05_POLECENIE_CLAUDE_M00.md` wraz z paczką. Pierwsze zadanie: sprawdzenie kodu, funkcji i gotowości API. Raport wraca do ChatGPT do recenzji według `06_RECENZJA_I_ODBIOR.md`.
6. `08_MAPA_POMOCY_I_ROZBIEZNOSCI.md` — powiązanie projektu z pomocą i pytania wymagające dowodu z repozytorium.

## Status

Gotowe: zaktualizowany plan, projekt zabezpieczeń, klikalne makiety najważniejszych przepływów, mapa zakresu i polecenie dla wykonawcy. Nie wykonano kompilacji Android/iOS, audytu aktualnego repozytorium ani testu produkcji. Opis w pomocy oznacza funkcję udokumentowaną, a nie niezależnie potwierdzone wdrożenie.

Dokumenty Markdown i prototyp tworzą jeden pakiet. `WERYFIKACJA.md` podaje rzeczywiście wykonane sprawdzenia. HTML/CSS/JS to makieta, nie kod do bezpośredniego wklejenia do produkcji.
